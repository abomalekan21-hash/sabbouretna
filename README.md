# منقوشة بزيت وزعتر

سبورة رسم مشتركة لحظية مع ألعاب: أي حدا بيفتح الرابط بيرسم ويلعب مع الباقيين فوراً، بدون حسابات ولا صلاحيات.

## شو فيها

- **ارسم**: سبورة طويلة، 6 ألوان طباشير، 5 أحجام خط (من ناعم كتير لعريض كتير)، ممحاة، وإيموجي بتحطه على السبورة بكبسة.
- **إكس أو**: أول واحد بيلعب بياخد X، وأول واحد ثاني بيلعب بياخد O. إذا إنت لحالك بتقدر تلعب الطرفين.
- **أربعة بخط**: لوحة 7 أعمدة × 6 صفوف. بتختار عمود والقرص بينزل لتحت، واللي بيصفّ 4 من لونه (عرضي أو طولي أو مايل) بيفوز. أول واحد بيلعب بياخد الأحمر والثاني الأصفر، وكل جولة جديدة بيبلّش اللي ما بلّش المرة الماضية.
- **ذاكرة الإيموجي**: 20 كرت (10 أزواج). اقلب كرتين، إذا طلعوا نفس الإيموجي بيضلّوا مكشوفين وبتاخد نقطة. قبل البداية الكروت بتنكشف للكل 5 ثواني.
- **الحية**: كل واحد إله حية، وفي دائرة بتنقل مكانها. اللي بياكل أكثر بيكبر، وأول واحد بيوصل طوله 20 بيفوز، أو الأطول لما تخلص الدقيقتين. إذا راسك خبط بحية ثانية، هي اللي بترجع صغيرة.
- **لوّن**: 18 رسمة للتلوين: 8 سهلة (بيت، وردة، شجرة، سيارة، سمكة، فراشة، صاروخ، قطة) و10 معقدة (زخرفة، طاووس، بومة، قلعة، سفينة، قطار، تحت البحر، منظر طبيعي، فانوس، شجرة زيتون). بتختار لون وبتضغط على أي جزء، واللي معك بيشوف تلوينك وبيلوّن معك، وبتقدر تنزّل الرسمة كصورة.
- لكل الألعاب: لما حدا يضغط «ابدأ اللعبة» بيوصل للثاني سؤال «مستعد؟ نعم / لا».

## تشغيل على جهازك

```bash
npm install
npm start
```

افتح http://localhost:3000

لتجربتها مع صاحبك على نفس شبكة الواي فاي: افتحوا `http://IP-جهازك:3000`

## رفعها على الإنترنت (Render)

1. ارفع المجلد على مستودع GitHub.
2. على render.com اعمل **New → Web Service** واختار المستودع.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. بيعطيك رابط، ابعته لصاحبك وخلص.

> Vercel ما بيشغّل Socket.io لأنه ما بيدعم سيرفر شغال طول الوقت. استخدم Render أو Railway أو أي VPS.

## ملاحظات

- لوحات منفصلة: `/r/أي-اسم` (أحرف إنجليزي وأرقام و `-` و `_`)، مثلاً `/r/game1`. كل لوحة إلها ألعابها.
- الرسومات بتنحفظ بملف `data/boards.json`. الألعاب ما بتنحفظ، بتبدأ من جديد لما السيرفر يعيد التشغيل.
- على خطة Render المجانية الملف بينمسح لما السيرفر يعيد التشغيل، والسيرفر بينام بعد فترة بدون زوار وبياخد شوي وقت ليصحى أول ما حدا يفتح الرابط.
- «تراجع» بيشيل آخر خط أو إيموجي حطيته إنت بس، و«امسح السبورة» بتمسح عند الكل.
- عدد أزواج لعبة الذاكرة بيتغير من `MEM_PAIRS` بـ `server.js`، وإعدادات الحية (السرعة، طول الفوز، مدة الجولة) من `SN` بنفس الملف.
- الملفات: `server.js` (السيرفر) و `public/board.html` (الصفحة).
