# سبورتنا

سبورة رسم مشتركة لحظية: أي حدا بيفتح الرابط بيرسم مع الباقيين فوراً، بدون حسابات ولا صلاحيات.

## تشغيل على جهازك

```bash
npm install
npm start
```

افتح http://localhost:3000

لتجربتها مع صاحبك على نفس شبكة الواي فاي: افتحوا `http://IP-جهازك:3000`

## رفعها على الإنترنت (Render)

1. ارفع المجلد على مستودع GitHub.
2. على render.com اعمل **New → Web Service** واختار المستودع.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. بيعطيك رابط زي `https://sabbouretna.onrender.com` — ابعته لصاحبك وخلص.

> Vercel ما بيشغّل Socket.io لأنه ما بيدعم سيرفر شغال طول الوقت. استخدم Render أو Railway أو أي VPS.

## ملاحظات

- لوحات منفصلة: `/r/أي-اسم` (أحرف إنجليزي وأرقام و `-` و `_`)، مثلاً `/r/game1`.
- الرسومات بتنحفظ بملف `data/boards.json`. على خطة Render المجانية الملف بينمسح لما السيرفر يعيد التشغيل، والسيرفر بينام بعد فترة بدون زوار وبياخد شوي وقت ليصحى أول ما حدا يفتح الرابط.
- «تراجع» بيشيل آخر خط رسمته إنت بس، و«امسح السبورة» بتمسح عند الكل.
- الملفات: `server.js` (السيرفر) و `public/board.html` (الصفحة).
